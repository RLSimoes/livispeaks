# Livi Speaks - Site Estático

Site estático das aulas particulares de inglês da Livia (Livi Speaks).

Pronto para GitHub Pages.

## Como publicar

1. Crie um repositório no GitHub.
2. Faça upload de todos os arquivos desta pasta (`index.html`, `css/`, `imagens/`).
3. Vá em **Settings → Pages** e publique a branch `main` na pasta raiz.
4. O site ficará disponível em `https://seu-usuario.github.io/nome-do-repositorio/`.
